Công cụ đọc file .plnx (Spaceman)

Kéo thả các file .plnx vào, công cụ tạo sheet "Vị trí" (khoang, tầng, số thứ tự) để dán vào data.xlsx.

1. Chọn file .plnx

Kéo thả nhiều file .plnx vào đây
hoặc bấm một trong hai nút bên dưới

2. Kiểm tra

Version lấy từ số đầu tên file ("7. Sữa UHT" là version 7; "0.5 Sữa UHT + 0.5 Sữa hạt" là version 0.5). Ô nào đỏ là chưa đọc được, bạn nhập tay. Có nhiều version thì cách nhau dấu chấm phẩy (ví dụ 0.5; 1).

Đối chiếu vài sản phẩm với sơ đồ trong Spaceman để chắc khoang, tầng, số thứ tự đúng.

3. Tải kết quả

Mở ViTri.xlsx, copy sheet "ViTri" vào file data.xlsx của bạn (chuột phải tên sheet, chọn Move or Copy, chọn data.xlsx, tick Create a copy), rồi up data.xlsx lên GitHub như bình thường.
